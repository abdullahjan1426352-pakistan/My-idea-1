# 🎓 Subject Scope Explorer

A small Streamlit app that uses a Google Gemini Flash model to explain the **scope** and **key points** of any field of study. Pick a subject (or type your own), choose your level, and get a structured overview you can download as Markdown.

## What you get for each subject

- **Overview** and **scope**: how broad the field is, plus its major sub-fields
- **Key points**: the core concepts every learner should know
- **Getting started**: prerequisites and an ordered learning path
- **Applications and careers**
- **Common misconceptions**
- One-click **Markdown download**

## Run locally

**1. Get a Gemini API key** (free tier available): https://aistudio.google.com/apikey

**2. Install and run**

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

**3. Provide your API key**, using any one of these:

- Paste it into the sidebar when the app opens (simplest), or
- Set an environment variable:
  - macOS/Linux: `export GEMINI_API_KEY="your-key"`
  - Windows (PowerShell): `$env:GEMINI_API_KEY="your-key"`
- Create `.streamlit/secrets.toml` (never commit this file):

  ```toml
  GEMINI_API_KEY = "your-key"
  ```

## Choosing the model

The app defaults to `gemini-flash-latest`, a Google alias that points to the newest Flash model. To pin a specific version, either edit the **Model** box in the sidebar or set `GEMINI_MODEL` (environment variable or secret), for example `gemini-2.5-flash`. Current model names are listed at https://ai.google.dev/gemini-api/docs/models.

## Deploy on Streamlit Community Cloud

1. Push this project to a **GitHub** repository (see below).
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **Create app** and choose the repository, branch (`main`), and main file path (`app.py`).
4. Open **Advanced settings** and:
   - choose Python 3.11 or 3.12;
   - paste your key into **Secrets**:

     ```toml
     GEMINI_API_KEY = "your-key"
     ```
5. Click **Deploy**. You will get a public `*.streamlit.app` URL.

> **Note:** if you store your key in the app's secrets, anyone with the link can use your quota. Either leave the secret out so each visitor enters their own key in the sidebar, or monitor usage in Google AI Studio. The app includes a short cooldown and caches repeated requests for an hour to reduce usage.

## Notes and limitations

- Content is generated by AI and can contain mistakes. Verify anything important.
- Custom subjects are limited to 80 characters and basic punctuation.
- Nothing is stored on a server; your API key lives only in your session (or in your deployment's secrets).

## Troubleshooting

| Problem | Fix |
|---|---|
| "API key was rejected" | Re-copy the key from AI Studio; make sure there are no spaces. |
| "Model name was not found" | Change the **Model** box to a current name, e.g. `gemini-2.5-flash`. |
| "Rate limit or quota reached" | Wait a minute, or use a key with a higher quota. |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` inside your virtual environment. |
